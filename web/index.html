使用说明

支持翻译的文件

  • 文本文件：txt / md / json / yaml / ini / cfg / srt / ass 等
  • 文档：Word / Excel / PPT / EPUB / HTML / PDF（PDF 自动分类：文字层直接提取，扫描件走 OCR）
  • 图片：PNG / JPG / WebP / BMP（批量识别图中文字并翻译，导出译文覆盖图）
  • 游戏剧本：rpy（Ren'Py 引擎）、ks（吉里吉里引擎，支持日文「」引号）
  • 资源包：吉里吉里 xp3（可解包翻译后重新封包；加密包不支持）
  • 编码自动识别：UTF-8 / UTF-16 / Shift-JIS（日文）/ GBK（中文）
  • 暂不支持：Unity/UE 等引擎的资源包、程序内嵌字符串

文档 / PDF

  1. 拖入文档到「文档」工作台（支持多文件，也支持整个文件夹递归导入），点「提取并翻译」
  2. PDF 提取方式可选：文字层（默认）或图片 OCR（文字层乱码/缺失时强制逐页识别）
  3. 翻译完成后点「编辑」可逐条修改原文与译文，改完点「完成」
  4. 点「导出」选格式与方式：格式有 原格式 / TXT / Markdown / HTML / Word / PDF；方式有 逐个写入文件夹 / 打包 ZIP
  5. 原格式导出保留排版；跨格式导出（如 Word → Markdown）只保留文字，标题层级与表格结构会丢失
  6. PDF 选「PDF」格式可保持原排版：文字层原位替换译文，扫描件整页渲染成图后覆盖译文

图片翻译

  1. 在「图片」工作台拖入图片或整个文件夹（也可点「选择文件夹」），子目录一并扫描
  2. 列表里勾选要处理的图片，点「开始识别并翻译」——先选图再跑 OCR，不会误跑全量
  3. 结果按文本平铺，行首是所属图片的缩略图；顶部切换 仅原文 / 对照 / 仅译文
  4. 点缩略图放大查看该张图的译文覆盖效果，点图片以外的空白处返回列表
  5. 点「编辑」可逐条修改原文与译文，导出覆盖图会使用修改后的译文
  6. 导出支持「导出多图」（选文件夹逐张写入）和「导出 ZIP」；勾选「同时导出文本对照」可一并输出 Markdown

游戏 / 使用方法

  1. 把游戏文件夹拖进窗口，或点击选择（自动识别文件编码，日文游戏无需手动转码）
  2. 扫描到 .xp3 资源包：点「解包并翻译」，包内文本会加入文件列表（标记【xp3】）
  3. 勾选文本文件 → 「提取并翻译」
  4. 左侧文件树查看译文，顶部切换 仅原文 / 对照 / 仅译文；点「编辑」可逐条修改原文与译文
  5. 「导出」下载 zip（保持原编码）；解包过的资源包可「封包为 xp3」（原包自行备份后替换）

翻译引擎

  • MyMemory：免费，无需配置，有每日额度
  • 百度翻译：国内稳定，免费额度，需 APP ID + 密钥
  • DeepL：需 API Key
  • OpenAI 兼容：本地 LLM（Ollama / LM Studio 等）

常见问题

  • 导出文件去哪了？点导出会弹系统另存为窗口，位置由你选；多文件导出会先让你选一个文件夹
  • Windows 提示“未知发布者”？点「更多信息 → 仍要运行」，程序没有病毒
  • 杀毒软件报警？属误报，添加信任即可
  • 译文中文显示为方块？原日文编码装不下中文时已自动转存 UTF-8，游戏可能需要中文字库
  • 加密的 xp3 暂不支持（会提示“已加密”）
  • 所有处理在本机完成，游戏文件不会被上传到任何服务器
