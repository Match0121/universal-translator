# 万能翻译站 · Universal Translator

[![爱发电](https://img.shields.io/badge/%E7%88%B1%E5%8F%91%E7%94%B5-%E8%AF%B7%E6%88%91%E5%96%9D%E6%9D%AF%E5%A5%B6%E8%8C%B6-946ce6?style=flat-square)](https://afdian.com/a/match0121)

> Windows 桌面端全能翻译工具：文件、文档、游戏、图片，拖入即译。
> Drag in files, documents, games or images — detect, extract, translate, done.

![导入界面](docs/assets/screenshot-import.png)

## 亮点

- **拖入即译**：单个文件、多个文件或整个文件夹拖进窗口，自动递归扫描、自动识别，无需挑选
- **逐条编辑**：文档 / 游戏 / 图片的预览界面都能直接修改原文和译文，改完导出即生效
- **导出自由组合**：格式（原格式 / TXT / Markdown / HTML / Word / PDF）× 方式（逐个写入文件夹 / 打包 ZIP）；导出 PDF 时保留标题层级、列表与表格
- **文档翻译**：Word / Excel / PPT / EPUB / PDF / HTML / Markdown / TXT；PDF 自动分类，文本型直接提取、扫描件走 OCR；PDF 导出保持原排版
- **图片批量翻译**：文件夹整批导入，先勾选再识别，结果按文本平铺带缩略图；点缩略图放大查看覆盖效果，导出覆盖图 ZIP 或逐张写入文件夹
- **系统另存对话框**：所有导出都弹系统窗口由你选位置，不会悄悄存进下载文件夹
- **游戏翻译**：Ren'Py / 吉里吉里剧本自动识别，xp3 解包 → 翻译 → 封包回写；编码自动检测（UTF-8 / UTF-16 / Shift-JIS / GBK），日文剧本免转码
- **多翻译引擎**：MyMemory（免费免配置）/ 百度 / DeepL / OpenAI 兼容接口（本地 LLM 也可）
- **完全本地**：所有处理本机完成，文件不出电脑；深浅双主题偏好自动记忆

## 快速开始

1. 从 [Releases](https://github.com/Match0121/universal-translator/releases) 下载 exe（Windows 10/11，无需安装任何依赖）
 - UniversalTranslator-v1.4.2.exe（~249MB）：含 OCR，图片翻译与扫描件 PDF 识别可用
2. 双击运行。首次提示「未知发布者」时点「更多信息 → 仍要运行」（未签名软件的标准提示，属正常现象）
3. 把文件或文件夹拖进窗口，等待扫描、翻译，导出译文

使用说明与更新日志已内置：右上角 ⚙ 设置。

## 支持的输入

| 类别 | 格式 | 说明 |
| --- | --- | --- |
| 文本文件 | txt / md / log / json / yaml / ini / cfg / srt / ass | 导出保持原编码写回 |
| 游戏剧本 | rpy（Ren'Py）、ks（吉里吉里） | 引擎自动识别 |
| 资源包 | xp3（吉里吉里） | 解包 → 翻译 → 封包回写；加密包不支持 |
| 文档 | docx / xlsx / pptx / epub / html / pdf | PDF 文本型 / 扫描件自动分流；文字层乱码时可强制图片 OCR；导出支持跨格式转换 |
| 图片 | png / jpg / webp / bmp | 文件夹批量导入，OCR 识别 + 平铺对照 + 覆盖图导出 |

暂不支持：Unity/UE 等引擎资源包、程序内嵌字符串。

导出格式组合：原格式 / TXT / Markdown / HTML / Word / PDF，方式可选逐个写入文件夹或打包 ZIP。
导出 PDF 时保留标题层级、列表、表格与代码块，可选页脚页码；目标文件夹里重名时自动加序号，不覆盖已有文件。

## 翻译引擎

| 引擎 | 说明 |
| --- | --- |
| MyMemory | 免费免配置，有每日额度 |
| 百度翻译 | 国内稳定，免费额度，需 APP ID + 密钥 |
| DeepL | 需 API Key |
| OpenAI 兼容接口 | 可接本地 LLM（Ollama / LM Studio 等） |

## 开发

```powershell
pip install pywebview
python desktop.py
```

内嵌窗口不可用时自动回退到系统浏览器（功能不变）。

打包：双击 `build.bat`，产物在 `dist\UniversalTranslator.exe`。

## 更新日志

### v1.4.2 (2026-11-13)
- **导出 PDF 保留文档结构**：Markdown 与 Word 源文件导出 PDF 时，标题层级、列表、表格、代码块、引用块都按原结构排，不再退化成一段段纯文字；Markdown 结构由 marked 渲染，Word 的标题样式与表格从 `styles.xml` / `w:tbl` 还原，排版为黑白极简
- **可选页脚页码**：导出面板新增页码开关，只在选 PDF 时出现，默认不显示
- **导出去掉多余标题**：md / docx / pdf 不再写入「译文文档」字样与版式说明，正文直接从第一行开始
- **修复导出静默覆盖同名文件**：写入文件夹时若已存在同名文件，自动改为 `xxx_2`、`xxx_3` 保存，原文件不动，结束后提示改名清单；ZIP 与单文件导出仍由系统对话框询问

### v1.4.1 (2026-11-02)
- **修复 Markdown / 文本文档提取不全**：目标是中文时提取器按汉字数量把整行判为中文就跳过，240 行的笔记只提出 2 条；现在提取全部内容，是否跳过交给翻译阶段判断
- **修复游戏翻译目标语言写死**：九处硬编码 `zh-CN`，切到英语或日语后中文剧本一行都提不出来
- **修复日文纯汉字词被误跳过**：`回復薬`、`勇者`、`薬草` 这类词不再被当成「已是中文」而漏译
- **新增应用图标**：重新绘制的「译」字图标，替换 PyInstaller 默认图标

### v1.4.0 (2026-10-24)
- **图片批量翻译**：文件夹拖入递归导入，先勾选再 OCR；结果按文本平铺并带缩略图，点缩略图放大查看覆盖效果
- **文档文件夹导入**：递归扫描子目录，同名文件用相对路径区分，不再相互覆盖
- **导出面板**：格式（原格式 / TXT / Markdown / HTML / Word / PDF）× 方式（逐个写入文件夹 / 打包 ZIP）自由组合
- **跨格式文本转换**：任意文档可导出为 TXT / Markdown / HTML / Word / PDF
- **逐条编辑**：预览界面直接修改原文与译文，失焦即保存，导出自动使用新内容
- **修复换语言不生效**：缓存 key 未包含目标语言，导致换目标语言后仍返回上一次译文
- **修复原文本即目标语言误报错**：原文已是目标语言时返回原文属正常结果，现在自动跳过不送翻
- **修复导出文件丢失**：pywebview/WebView2 静默拦下 `<a download>`，全部导出改为系统另存对话框
